# Entrega 2 – Analítica de Datos

## Descripción

Este proyecto implementa el manejo y procesamiento de archivos CSV y JSON mediante Python, utilizando programación orientada a objetos.

Se desarrollaron tres clases independientes para importar, modificar y guardar información, además de generar un archivo de resumen con los resultados del procesamiento.
